# disc/

Сюда кладутся файлы с **вашего собственного** диска Crash Bandicoot 3: Warped.
Содержимое этой папки игнорируется git и никогда не попадает в репозиторий.

Для декомпиляции нужен только главный исполняемый файл из корня диска:

| Версия         | Код диска  | Файл          | `VERSION` |
|----------------|------------|---------------|-----------|
| США (NTSC-U)   | SCUS-94244 | `SCUS_942.44` | `us` (основная) |
| Европа (PAL)   | SCES-01420 | `SCES_014.20` | `eu`      |
| Япония (NTSC-J)| SCPS-10073 | `SCPS_100.73` | `jp`      |

Имя файла указано в `SYSTEM.CNF` в корне диска (строка `BOOT = cdrom:\...`).

Как достать файл:

- **С диска:** вставьте диск в привод компьютера и скопируйте `SCUS_942.44`
  из корня диска в эту папку.
- **Из образа `.bin/.cue`:** смонтируйте образ (WinCDEmu на Windows, `cdemu` на
  Linux) и скопируйте файл. Другой способ — распаковать образ утилитой
  `dumpsxiso` из проекта mkpsxiso: `dumpsxiso -x out game.bin`.

Проверить файл: `python3 tools/psexe.py disc/SCUS_942.44`.

Для будущего ПК-порта понадобятся и остальные файлы диска: уровни `*.NSF`/`*.NSD`,
музыка и видео. Их тоже нужно будет брать с вашего диска. Пока для декомпиляции
они не нужны.
