# ПК-порт на Android

`make pc-android` собирает `build/android/crash3.apk` — порт как приложение
Android без Java-кода (NativeActivity) для 32-битного ARM (`armeabi-v7a`).

## Сборка

Официальный Android NDK не нужен: в `tools/android/` лежит минимальный
интерфейс Android (заголовки C-библиотеки bionic для 32-битного ARM, манифест),
`src/pc/android_ndk.h` — нужная часть API NDK, а заглушки системных библиотек
для компоновки `tools/pc/build.py` делает сам из списка разрешённых функций.
Нужны (Ubuntu): `gcc-arm-linux-gnueabi` (компилятор и `libgcc`), `clang` и
`lld` (компоновка), `aapt`, `zipalign`, `apksigner`, `android-sdk-platform-23`
(`android.jar`), JDK (`keytool`). APK подписывается отладочным ключом
`build/android-key.jks` (создаётся один раз; с тем же ключом приложение
обновляется поверх).

APK содержит перекомпилированный код игры из вашего исполняемого файла: он
только для себя, не публикуйте его.

## Требования к устройству

- Поддержка 32-битных приложений (`armeabi-v7a`). Порт держит память
  PlayStation по её адресам (`0x80000000`), это возможно только в 32-битном
  процессе. Если Android пишет «приложение несовместимо», значит, прошивка
  устройства 32-битные приложения не запускает.
- Scratchpad на Android не по `0x1F800000` (там куча Java), а сразу после RAM,
  по `0x80200000` (`PSX_SCRATCH` в `include/types.h`; перекомпилированный код
  строит его адрес через `RC_SCRATCH_HI`, указатели на него в данных образа
  поправляются при запуске).

## Как пользоваться

1. Установите APK (разрешите установку из неизвестных источников).
2. При запуске разрешите доступ к файлам. Если окно не появилось:
   Настройки → Приложения → «Crash 3 (порт)» → Разрешения → Файлы.
3. Положите образ своего диска (`.cue` вместе с `.bin`, или `.iso`) в папку
   `Crash3` во внутренней памяти (`/sdcard/Crash3`) или в «Загрузки»
   (`/sdcard/Download`). Приложение найдёт его само.

Управление — сенсорные кнопки поверх картинки (крестовина слева; справа
X — прыжок, SQ — вращение, O, TR; сверху START, SEL, L1/R1, L2/R2) или
Bluetooth-геймпад. Лог порта и игры — `crash3_log.txt` рядом с образом.

Звука пока нет (как и в версиях для ПК).

## Что уже нашлось на устройстве

- Загрузчик Android прибавляет адрес загрузки библиотеки к абсолютным
  символам: адреса PlayStation не должны экспортироваться (библиотека
  экспортирует только `ANativeActivity_onCreate`, сборка это проверяет).
- Дальние вызовы lld в позиционно-независимом коде (`__ARMV7PILongThunk`)
  считают адрес относительно библиотеки: вызывать по абсолютному адресу
  PlayStation нельзя. Код по таким адресам (оверлей) идёт через
  интерпретатор.
- При падении приложение показывает сигнал, адрес и PC; место в коде —
  `llvm-addr2line -e build/android/lib/armeabi-v7a/libcrash3.so` с
  PC − (база − адрес `ANativeActivity_onCreate` в этой сборке).
