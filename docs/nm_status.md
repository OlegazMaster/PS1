# Функции без совпадения (NON_MATCHING)

Все они написаны на C и, по ручной сверке с ассемблером, работают как
оригинал. Обычная сборка берёт для них оригинальный ассемблер (`#else
INCLUDE_ASM`), сборка `make NON_MATCHING=1` — C.

Оценки получены `tools/decomp/scoreall.py`: `raw` — сколько строк
инструкций отличается, `norm` — то же после замены имён регистров на одно
(0 значит: отличаются только регистры), `len` — длина оригинала в
инструкциях. Оценки сняты в начале этой части работы; функции, совпавшие
после этого, из таблицы уже убраны. `длинная` — функция в
`config/us/nm_too_long.txt` (на C длиннее оригинала).

Самые перспективные — сверху (малые `norm`/`raw`). В заметках — что уже
пробовали, чтобы не повторять.
